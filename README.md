# Text Quest Game — текстовый квест на Java

Учебный проект для курса JavaRush (модуль «Java Professional»). Веб-приложение — интерактивный текстовый квест с ветвлением сюжета. Пользователь проходит историю, делая выбор на каждом шаге, и в зависимости от решений приходит к победе или поражению.

## Функционал

- Ветвящийся сюжет: 7 шагов, 4 финальных исхода (2 победы, 2 поражения).
- Страница-приветствие с предысторией и вводом имени игрока.
- Сохранение состояния игры и статистики в HTTP-сессии.
- Статистика: всего игр, побед, поражений, процент побед.
- Возможность начать игру заново без потери статистики.
- Обработка пустого имени (заменяется на «Аноним»).
- Обработка некорректных выборов и ошибочных состояний.

## Стек

- Java 11
- Servlet API 4.0
- JSP + JSTL
- Maven 3 (сборка WAR)
- Apache Tomcat 9 (контейнер сервлетов)
- JUnit 4 + Mockito (тестирование)

## Требования

- JDK 11+
- Maven 3.6+
- Apache Tomcat 9.0.x

## Как запустить

1. Соберите проект: `mvn clean package`.
2. Скопируйте `target/text-quest-game.war` в папку `webapps/` Tomcat.
3. Запустите Tomcat: `bin/startup.sh` (или `bin\startup.bat` на Windows).
4. Откройте в браузере: `http://localhost:8080/text-quest-game/`.

Альтернативно — импортируйте проект в IntelliJ IDEA Ultimate, настройте Tomcat 9 как Run Configuration и запустите напрямую.

## Тесты

- `GameStateTest` — обновление статистики, сброс игры без потери статистики, обработка пустого имени.
- `QuestFlowTest` — проход по всем 4 финальным путям, проверка побед/поражений.
- `RestartServletTest` — сброс шага с сохранением статистики, обработка null-состояния (с моками HttpSession и HttpServletRequest).

Запуск: `mvn test`.

## Известные ограничения

- Статистика хранится per-session, не глобально (обнуляется при новой сессии).
- Сюжет захардкожен в `QuestTree` — не вынесен в файл.
- Нет логирования (только `System.err`).
- Нет защиты от race condition при одновременных запросах из одной сессии.
